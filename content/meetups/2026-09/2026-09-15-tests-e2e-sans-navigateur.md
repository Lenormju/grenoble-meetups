Préparez votre rentrée avec la prochaine soirée de La QualiSphere ! Emilie et Stéphane vous parleront de ce qu'ils ont mis en place sur leur projet chez Moody's.

Une nouvelle application avec une API et une UI ? C'est parti pour de fastidieux tests e2e : instabilités, lenteurs, couplage avec la UI... Emilie et Stéphane proposent d'étudier une approche des tests e2e sans UI ni navigateur, via une API construite autour de HATEOAS. Les promesses ? Écrire, servir mais aussi tester son métier via une API bien documentée.

Moody's nous accueillera dans ses locaux à Montbonnot de 18h30 à 20h. Pour celles et ceux qui souhaiteraient poursuivre la soirée, il y a un bar pas très loin : le QG, où nous pourrons envisager de continuer les échanges.
